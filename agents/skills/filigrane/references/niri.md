# niri desktop

- Config: `dotfiles/config/niri/config.kdl` (linked to `~/.config/niri/`). `niri validate` before saving; niri reloads on save.
- `environment {}` sets `CHROME_FLAGS` (Void's chromium wrapper reads only that, no flags file) and `ELECTRON_OZONE_PLATFORM_HINT`. Autostart: `spawn-at-startup` lines.
- Keys (bépo right hand, arrows also work): `Mod+T/S/R/N` = left/down/up/right, `Ctrl` moves, `Shift` changes screen. `Mod+Return` foot, `Mod+Space` menu, `Mod+D` app launcher, `Mod+Y` AI agent (`fili-ai`), `Super+Alt+L` lock. `Mod+Shift+/` lists them.
- Personal additions: `users/<login>/dotfiles/config/niri/local.kdl` (included at the end of `config.kdl`).
- Shell: Quickshell, one process for the bar, notifications and the menu picker (replaces waybar, mako, fuzzel): `dotfiles/config/quickshell/` (`Bar.qml` modules, `Notifs.qml`, `Picker.qml`, `Theme.qml` colours, `Control.qml` commands). Software rendering (`QT_QUICK_BACKEND=software` pragma in `shell.qml`, no GL context: about half the memory). Scripts talk to it with `~/.local/bin/fili-shell` (named pipe, no Qt client): `signal N` refreshes bar modules (was `pkill -RTMIN+N waybar`), `dnd on|off|toggle`, `dismiss-all`, `history`, `history-json`, `dmenu` (fuzzel-compatible options), `picker-close`, `reload`. Reload after editing: `fili-shell reload`; logs: `/run/user/$UID/quickshell/`.
- Menu: `~/.local/bin/menu` (`fili-shell dmenu`, one fuzzy list: `~/.config/menu/entries`, .desktop apps, "Category: Action" entries; `menu <section>` jumps to clip, emoji, calc...). `Shift+BackSpace` up one level, `Escape` quits. The picker window itself is the blurred backdrop (layer namespace `menu-backdrop`).
- Bar modules: script modules (`Mod.qml`) use the waybar custom JSON protocol (`bar-status`, `bar-tray`, `bar-alert`...); CPU/RAM/temperature/disk/network from `apps/bar-stats` (resident, no forks); rarely-changing indicators (SSH, airplane, VPN, night light, backup, calendar, low battery) are not polled: `bar-stats watch` reads /proc and /sys and sends `signal N` on change. Audio, MPRIS, Bluetooth, tray, keyboard layout, workspaces are native. New indicator: prefer a signal over an `interval`.
- Wallpaper: static `swaybg` via `~/.local/bin/wallpaper [image]`, images in `~/.local/share/wallpapers/`. Never animated.
- Visual changes follow `references/brand.md`.
